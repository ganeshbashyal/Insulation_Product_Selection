# Customer Support — Quick Triage Guide

*Rapid symptom → cause → solution reference for front-line supplier staff.*

---

## Symptom → Likely Cause → Solution

| Customer says | Likely cause | First action |
|---------------|--------------|--------------|
| "House too cold in winter" | Under-insulated ceiling/walls | Check R-value vs climate zone; recommend upgrade |
| "House too hot in summer" | Heat gain, dark roof, no reflective | Reflective foil + light roof + higher R |
| "Bills still high after insulating" | Gaps, bridging, draughts, glazing | Check install quality + sealing |
| "Mould on ceiling/walls" | Condensation + poor ventilation | Find moisture source + ventilate |
| "Condensation on windows" | High humidity | Ventilate + reduce moisture |
| "Water dripping from roof" | Condensation under metal roof | Foil blanket + roof ventilation |
| "Insulation is wet" | Leak or condensation | Fix source + replace wet insulation |
| "Mould in corners/wardrobe" | Thermal bridge + stagnant air | Insulation continuity + airflow |
| "Can hear neighbours" | Party wall under-rated | Acoustic batts + seal gaps |
| "Footsteps from upstairs" | Impact sound | Floating floor / resilient layer |
| "Traffic noise" | Glazing (not insulation) | Double glazing / acoustic seals |
| "Noise between rooms" | Internal walls uninsulated | Acoustic batts in internal walls |
| "Echo in room" | Absorption issue | Acoustic panels / soft furnishings |
| "Which R-value?" | Unknown climate zone | Determine zone → recommend R |
| "Which material?" | Confused options | Match to priorities (cost/fire/itch) |
| "Foil vs batts?" | Reflective vs bulk confusion | Explain different jobs |
| "DIY install?" | Wants to self-install | PPE + technique + electrical safety |
| "Around downlights?" | Fire/electrical risk | IC-rated fittings + clearance |
| "Insulation sagging" | Poor install / loose-fill | Re-secure or replace |
| "Itchy insulation" | Glasswool irritation | PPE or polyester option |
| "Permit needed?" | Compliance | Usually no, but 7-star applies |
| "Meet NCC?" | Compliance assurance | AS/NZS 4859.1 + R-value |
| "Foil safe around wiring?" | Electrical | Professional install + non-conductive staples |
| "Bushfire zone?" | BAL rating | Non-combustible insulation |
| "Warranty?" | Warranty | Varies (Bradford 70yr, Foilboard 25yr) |
| "Termites?" | Pest concern | Termite barrier + inspection |
| "Health issues?" | Fibres/VOCs | Bio-soluble + low-allergen options |

---

## The 5 golden questions to ask every customer

1. **Where are you located?** (determines climate zone → R-value + condensation requirements)
2. **What's the building type?** (house/apartment/shed — determines NCC class + requirements)
3. **What's the problem exactly?** (thermal/acoustic/moisture — determines the solution)
4. **New build or existing?** (determines install method + compliance path)
5. **What's your priority?** (cost / comfort / fire / non-irritant / acoustic — determines material)
