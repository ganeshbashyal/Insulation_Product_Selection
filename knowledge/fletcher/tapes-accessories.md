# Fletcher Membrane Tapes and Thermal-Break Accessories

Accessory family covering Thermatape, Vapastop 883 foil tape, plain foil tape and 3M seaming tape. Identify the parent system and required function before choosing a type. Thermatape performance changes under compression; membrane and foil tapes are not standalone insulation.
