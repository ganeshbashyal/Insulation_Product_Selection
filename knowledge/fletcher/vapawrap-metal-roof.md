# Sisalation Vapawrap Vapour Permeable Metal Roof

## Canonical description

This is Fletcher's vapour-permeable membrane family for suitable metal-roof assemblies. Its function is moisture/water management within a designed roof, not bulk thermal insulation and not Permastop glasswool blanket. Roof slope, support, drainage, ventilation, climate and condensation analysis determine suitability.

## Selection logic

Use when the roof design specifically requires a vapour-permeable metal-roof membrane. Use Vapawrap Wall for walls; Permastop for faced bulk blanket; E-Therm/Foam Cell/Bubble Cell only where their reflective/foam system is specified. Never choose solely on similar foil appearance.

## Installation and clearances

Extracted from the manufacturer datasheet; the bot may share this context but must not issue project-specific installation instructions or override the human-reviewed install guide.

1. Install as a continuous membrane over rafters/trusses beneath metal roof
battens, or draped between battens.
2. Roll out horizontally starting from the
eaves, ensuring lower edge drains directly into the gutter.
3. Allow a
minimum 150mm overlap for horizontal laps (or 50mm if fully taped with VapaSeam
tape).
4. Allow a nominal 40mm drape between framing members to create a drainage
channel for condensation.
5. Fix temporarily with staples or clouts to rafters,
then secure permanently with roof battens.
6. Tape all laps, penetrations, and
ridgelines with Sisalation VapaSeam Tape for complete airtightness.
7. Fix metal
roof cladding directly to battens above the membrane.

**Manufacturer-stated limitations**

- Designed specifically for metal roof applications; do not use
as a primary roof cladding.
- Must not be left exposed to direct UV sunlight
beyond manufacturer recommended exposure time.
- Ensure membrane has continuous
fall to gutters without reverse laps or ponding.
